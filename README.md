# NEGM BOT LAB
واجهة عربية RTL لصناعة بوتات تيليجرام بالأوامر، ومعاينة Python وتصدير ZIP.

## ملفات المشروع
- `index.html`: الواجهة.
- `style.css`: التصميم المتجاوب.
- `app.js`: التفاعل والاتصال بالـ API.
- `backend/main.py`: FastAPI، تخزين المشاريع، توليد الكود، التصدير وإدارة التشغيل.
- `backend/requirements.txt`: المكتبات.
- `backend/Dockerfile`: صورة حاوية.

## التشغيل المحلي
Python 3.10+ مطلوب:
```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
افتح `index.html` من خلال خادم ملفات ثابت، مثل:
```bash
python -m http.server 5500
```
ثم افتح `http://localhost:5500` واضبط `apiRoot` في `app.js` إلى `http://localhost:8000` إذا احتجت ذلك. عند تجربة الموقع على هاتف استخدم IP جهاز الكمبيوتر بدل localhost، وعلى الشبكة نفسها.

## الاستخدام
1. أنشئ بوتًا عبر Telegram @BotFather وخذ التوكن سرًا.
2. أنشئ مشروعًا من الموقع، أضف أوامر وردودًا واحفظها.
3. من تفاصيل المشروع أدخل التوكن واضغط تشغيل، أو نزّل ZIP وشغّله مستقلًا.
4. ملف ZIP يتضمن `bot.py` و`requirements.txt` و`README.md` و`.gitignore`.

## النشر
يمكن نشر الواجهة على GitHub Pages، والخلفية على خدمة تدعم Python/Container وعمليات طويلة العمر. ضع `BOT_TOKEN` في Environment Variables للبوت المستقل. للـ API العام: استخدم HTTPS، واضبط `CORS_ORIGINS` على نطاق الواجهة، وأضف مصادقة وصلاحيات لكل مستخدم، وقرصًا دائمًا لملفات المشاريع. الخدمات المجانية قد تنام أو تفرض حدودًا؛ تحقق من الشروط الحالية قبل الاعتماد على تشغيل 24/7.

## حدود الأمان
هذه نسخة MVP وليست جاهزة لفتحها للعامة. التشغيل يرسل التوكن إلى الخادم ويستخدمه في بيئة العملية؛ لا تستخدم خادمًا لا تثق به. المشاريع محفوظة في ملف JSON محلي، ولا يوجد تسجيل دخول/عزل حسابات في هذه النسخة. الكود الذي يولّده الخادم يأتي من قالب ثابت وردود نصية؛ لا تضف تشغيل Python حر يرفعه المستخدمون إلى العملية الرئيسية. قبل إطلاق عام، أضف المصادقة والعزل وحدود الموارد وتخزين الأسرار الآمن.
